# Madar glossary

Terms used across Madar. Architecture constraints belong in the [overview](./overview.md).

## Language

**User**: The person using Madar to manage MikroTik User Manager.

**Client**: The web UI used by the Electron desktop app.

**Environment**: One running Madar server and the machine, credentials, and state it owns.

**Madar home**: The base data directory. Runtime state lives under its `userdata` directory.

**Agent**: A coding agent working on this repository.
