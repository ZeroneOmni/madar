# Install Madar

Download a desktop installer from [Madar releases](https://github.com/ZeroneOmni/madar/releases). Windows uses NSIS, macOS uses a DMG, and Linux offers AppImage and Debian packages.

For the CLI alone, download and inspect [install.sh](../../scripts/install.sh) for macOS/Linux or [install.ps1](../../scripts/install.ps1) for Windows, then run it locally. The launcher command is `madar`. CLI archives are also attached to releases.

Madar is being adapted for MikroTik User Manager. Its coding workspace has been removed, and User Manager workflows are not implemented yet. See the [project README](../../README.md) for current scope.
