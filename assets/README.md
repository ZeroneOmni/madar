# Madar icons

The SVG in each of `dev/`, `nightly/`, and `prod/` is the editable source for that channel's Madar icon.
Run `vp run icons:export` to generate desktop PNGs, multi-size Windows ICOs, and web favicons on any platform.
Run `vp run icons:check` to verify generated assets match their sources. Both commands also cover the development favicons in `apps/web/public`.
